## 2. 모델 구성

- **타깃/구조**: 1WAY 직접 `control_success`. way 분해 없음.
- **결합 방식**: `p = r + w_cb(p_cb − r) + w_ft(p_ft − r) + w_mlp(p_mlp − r)`,
  `r = 0.47469` (시즌별 성공률 선형 외삽), `w = 0.5993 / 0.2902 / 0.1211`
  (val 2024·2022 에서 `w* = M⁻¹A`, 두 해 평균).
- **베이스 학습기**: CatBoost(RMSE, depth 5, lr 0.02 × 3000트리, `l2_leaf_reg` 10000, 3시드)
  + FT-Transformer(`d_token` 64, 3층, 8헤드, drop 0.1, 입력 168)
  + 잔차 MLP(width 384, depth 3, drop 0.3, 입력 336 = 168 + 결측마스크 168).
- **하이퍼파라미터**: `tuning/tune_cb.py` 5라운드 × 40설정 × 2해 × 8시드로 포화 확인.
  채택근거 t = 16.2 / 27.7. `l2_leaf_reg` 30000 에서 꺾인다. 전문은 `models/cw_v17_base/`.
- **피처 세트**: 168 = 원본 72 + 시즌폼 8 + TrackMan 55 + 볼카운트 27 + 역할 5 + 결측표시 1.
  모든 룩업은 **직전 시즌까지**로만 만든다 (s년 행은 s년 미만 데이터 룩업).
- **학습 구간**: 배포본 2019~2024 전체. val 예측은 해당 시즌을 빼고 냈다 (아래 5절).
- **후처리**: 없음. v16 에 있던 리더보드 역산 상수(target_rate 0.47353, 전역 배율 1.0721)를
  **전부 제거**했다. 08-21 데이콘 재공지가 허용 출처 4가지를 못박았고 리더보드는 거기 없다.
  그 대가로 990 → 983 (−7) 을 감수한 판이다.

## 3. 앙상블 관점

val2024 실측 (n=253,507):

| 상대 모델 | 확률 상관 | 오차 상관 | 최적 가중(2024 자체적합) | 결합 2024 all |
|---|---:|---:|---:|---:|
| `sj_cb_ft_fonly` | **0.9892** | 0.9999 | **0.00** | 887.7 (Δ **+0.0**) |
| `hw_v12` | 0.9038 | 0.9992 | — | — |
| `yn_fa10c` | 0.8800 | 0.9990 | — | — |

**★ 예전 메모("cw 가 유일한 비상관 멤버, ρ 0.8959")는 이제 맞지 않는다.**
그 값은 sj 의 **구 279피처 하네스** 시절 것이다. 지금 sj 라인은 §27 결정으로
**cw 의 v17 ML 스택 자체를 동결해 쓰고** 있어서 두 예측이 사실상 같은 모델이 됐다
(ρ 0.9892 — 팀 4자 중 **최고**). 결합 이득이 0 인 이유가 이것이다.

정직 전이 검사 (결합층 규칙: fit fold(N−1) → freeze fold(N)):

```
fit(2022)  w* = 0.72   2022  2,481.5 -> 2,501.6
freeze -> eval(2024)          887.7 -> 852.1   (Δ -35.6)
```

**2022 에서 고른 가중치가 2024 에서 −35.6 으로 뒤집힌다.** 두 해에서 우열이 반대라
가중치가 폴드를 못 넘는다. 행 CV 나 한 해 자체적합으로 골랐으면 이걸 못 봤다.

- 이 모델이 **남과 다르게 맞히는 구간**: **2022 F** (139.8 vs sj 63.3). 2024 F 는 반대로 약하다(332.9).
- 결합에서 빼야 하는 조건: sj 라인이 v17 스택을 계속 동결해 쓰는 한 **sj 와의 2-way 결합은 이득 0**이다.
  cw 를 살리려면 sj 쪽이 v17 과 다른 스택으로 갈라져야 한다.
