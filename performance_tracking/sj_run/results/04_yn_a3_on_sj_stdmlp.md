# 04 — yn A3 3피처를 sj_stdmlp 원본에 이식 (1단계 ablation)

**실행**: 2026-08-29 ~ 08-31, sj_run 자동 루프. RTX 4080 SUPER.
**재현**: `yn_a3/` (원자 정의는 `cowork/sj/sj_final/src/atoms.py` 의 `futures3`).

## 4줄 요약

1. **무엇**: 176열 뒤에 A3 3열을 붙여 CB·stdMLP 를 각각 3시드로 재학습, 고정 보정·고정
   결합가중으로 4구성(BASE176/A_CB/A_MLP/A_BOTH)을 조립해 2024·2022·2023 에서 판정.
2. **수치**: 팀 결합 후 배포보정 기준 A_BOTH 가 val2024 **896.7→900.6(+3.9)**,
   val2022 **2348.5→2351.0(+2.6)**, 2022R **+2.8**, 2023R **+0.3**.
3. **관문**: A_BOTH 만 4관문 전부 통과. 단 관문1(≥900)을 **0.6**, 2023R 을 **0.3** 차로 넘어
   3시드 잡음과 구분되지 않는다. 8시드 paired 확인은 **미완**(4 arm 중 1개만 완료).
4. **ZIP**: 생성 안 함. 8시드 확인 전에는 굽지 않는다.

## 1. 구현 — 누수는 구조적으로 막힌다

`atoms.py` 에 `futures3` 원자를 추가했다. `run_arm.py:270` 이 학습행을
`season <= fold-1` 로 자르고 그 마스크가 그대로 원자에 넘어오므로, lookup 을 `F.tr`
로만 만들면 yn 이 요구한 "season < S" 가 코드 경로상 보장된다. 미등장 선수는 NaN,
기존 176열은 손대지 않고 뒤에 3열만 붙인다. 정의는
`models/yn_fa10c/script_fa10c_inference.py` 의 `add_futures_features` 와 같다.
(yn 이 지목한 `../experiments/feature_engineering_20260819/build_features.py` 는 이 PC 에 없다.)

나는 이득이다. 이 저장소 전례상 상관 이득의 전이율(0.99)이 피처 이득(0.62)보다 높다.

## 5. 8시드 확인 미완 + GPU 스래싱

`S8_cb_base` 만 끝났다(8시드 3폴드): 2024 **902.6** · 2022 **2480.6** · 2023 212.1.
3시드(900.0 / 2479.7 / 211.1)와 큰 차이 없다 — 8시드가 3시드를 뒤집지는 않는다는 신호다.

나머지 3 arm 은 미완이다. **원인은 계산량이 아니라 VRAM 경합**이다:

```
cb seed0  (138403초)  ← 38시간      정상 시드는 15~20초
cb seed3  ( 54710초)  ← 15시간
Warning: less than 75% GPU memory available. Free: 7198 / 16375
```

VRAM 을 잡은 것은 학습 프로세스 하나뿐이고 나머지 20여 개는 전부 그래픽(Chrome·Edge·
Discord·Steam·ChatGPT·Claude 앱). **GPU 작업 전에 이것들을 닫아야 한다.**
같은 사고가 08-30 항목 M GPU 빌드에서도 났다(depth 7, seed0 에 138,491초).
