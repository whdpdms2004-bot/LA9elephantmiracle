# A/B/C 실험 결과 (경기그룹 K-fold · 205피처)

## 설정 (이번 라운드에서 이렇게 했다)
- **예측 시점**: 엄격 투구 전 (현재 투구의 물리·위치·구종·결과 전부 제외)
- **분할**: `GroupKFold(game_pk)` 경기그룹 **번갈아** K-fold → **모델 선택 전용**, **test 2019 고정**
- **모델**: 로지스틱 + GBM(HistGB·LightGBM·XGBoost), 하이퍼파라미터 고정
- **표본**: 상위 40투수 (train 238,054 / test 94,150), 투수별 임계 4,500
- **피처 205개**: 기존 + **신규** `_car`(전 기간) · `_l100`/`_l500`(최근 N구) · 아스널 `_2w`

Baseline LogLoss: 리그평균 **0.5957** · **count-only 0.5790** · pitcher_te 0.5947

---

## B · 전체 단일 모델
| 모델 | CV | TEST 2019 | ROC-AUC | ECE |
|---|---|---|---|---|
| **HistGB** | 0.5727 | **0.5760** | 0.6274 | 0.0159 |
| LightGBM | 0.5756 | 0.5772 | 0.6255 | 0.0134 |
| LogReg | 0.5748 | 0.5789 | 0.6204 | 0.0141 |
| XGBoost | 0.5735 | 0.5810 | 0.6227 | 0.0327 |

- **HistGB가 최고**(0.5760). count-only(0.5790) 대비 **−0.0030**, 리그평균 대비 −0.0197.
- 로지스틱도 0.5789로 count-only와 거의 동급 → **선형으로도 대부분 설명**된다.
- XGBoost는 CV 2위인데 TEST 최하위(+0.0075 격차) → **번갈아 CV의 낙관 편향**이 모델 선택을 왜곡할 수 있음.

## A · 투수별 모델
| 모델 | CV | TEST 2019 | ROC-AUC | 커버리지 |
|---|---|---|---|---|
| **XGBoost** | 0.5842 | **0.5865** | 0.6011 | 1.00 |
| LightGBM | 0.6034 | 0.6049 | 0.5838 | 1.00 |

- 최고 투수별(0.5865) vs 최고 전체(0.5760) → **전체가 +0.0105 우위**. 투수별 완전분리는 여전히 열등.
- 다만 **XGBoost 투수별(0.5865)은 이전 라운드(0.61~0.64)보다 크게 개선** — 트리 수를 줄이고(80) 규제를 키운 효과.
- 커버리지 1.0(상위 40투수 전원 임계 통과) → 폴백 없음.

## C · 구종 예측 정보 (stacking)
- 구종 보조모델: 7클래스, **TEST top-1 42.7%** (최빈 baseline 33.8%) → 투구 전 정보만으로는 구종 예측이 어렵다.
- OOF(경기그룹) 예측으로 누수 차단 후 CSW 모델에 `pt_hat_*`·`pt_entropy`·`pt_max` 추가:

| | CV | TEST 2019 | 피처수 |
|---|---|---|---|
| 구종정보 없음 | 0.5842 | **0.5855** | 290 |
| 구종정보 추가 | **0.5832** | 0.5869 | 299 |

- **CV는 개선(−0.0010)인데 TEST는 악화(+0.0014)** → 구종 확률이 in-sample에만 도움. 실질 이득 없음.

## 종합 결론
1. **전체 단일 > 투수별 완전분리** (0.5760 vs 0.5865). 개인화하려면 **부분 풀링**(전체 + 투수별 보정)이 맞다.
2. **최고 성능도 count-only 대비 −0.003 수준** — 신호 천장이 낮다는 기존 결론 유지. 신규 피처(career·최근 N구·아스널 2w) 205개를 넣어도 크게 달라지지 않았다.
3. **구종 예측 정보는 도움 안 됨**(TEST 기준). 구종 모델 정확도 42.7%로 정보량이 부족.
4. **번갈아 K-fold는 낙관 편향이 실측됨** — XGB(CV 2위→TEST 4위), C(CV 개선→TEST 악화) 두 사례. **모델 선택은 시간순(롤링-오리진) 분할로 하는 게 안전**하다.
