# D / E / F 결과 — EDA로 방향 조정 → 피처 확장 → CS·W 분해

Baseline: 리그평균 **0.5957** · **count-only 0.5790** (TEST = 2019, 94,150투구, 상위 40투수)

## 성능 요약 (TEST 2019 LogLoss ↓)

| 단계 | 모델 | LogLoss | ROC-AUC | ECE |
|---|---|---|---|---|
| A/B 라운드 최고 | HistGB (205피처) | 0.5760 | 0.6274 | 0.016 |
| E | full피처(342) + Optuna 40 | 0.5734 | 0.6332 | — |
| F | 단일 is_csw (튜닝) | 0.5736 | 0.6334 | 0.0057 |
| **F** | **분해 결합 (튜닝)** | **0.5722** | **0.6368** | 0.0061 |
| F | 앙상블 단일+분해 | 0.5722 | 0.6369 | 0.0059 |

**누적 개선**: 0.5760 → **0.5722** (−0.0038), AUC 0.6274 → **0.6368** (+0.009). count-only 대비 −0.0068.

---

## D · EDA에서 얻은 방향 조정
1. **CSW는 두 사건의 합** — called 0.166 + whiff 0.116. 스윙률 0.47, 스윙 중 헛스윙 0.25, 지켜본 중 콜스트라이크 0.31 → **분리 모델링(F)의 근거**
2. **카운트가 지배적** — 0-2에서 0.186 vs 3-0 부근 최고. 2스트라이크에서 급락(커트/보호 스윙)
3. **★ 천장 진단** — 현재 투구 **위치**만 추가하면 AUC 0.613 → **0.739**. 우리 342개 투구 전 피처 전부는 0.613 → 0.633.
   → **신호의 대부분이 "그 공이 어디로 갔는가"에 있고, 이는 정의상 투구 전에 알 수 없다**
4. **★ 비율 예측은 이동평균이 우세** — 경기단위 CSW% R²: 이동평균 0.244 vs 모델 0.075

## E · Pitch Predict 차용 피처 (+137개 → 총 342)
- `batter_scout`: 구종 카테고리(fb/br/off)별 타자 상대빈도·헛스윙률·콜스트라이크허용률·chase률·스윙률
- `gameflow`: 직전 3구 존/스윙/CSW, 최근 5·15구 카테고리 비율·스트라이크율
- `prior_ab`: 삼진·볼넷·안타·홈런 직후 플래그 / `lineup`: 타순 슬롯
- 전부 `shift(1)` expanding (원문은 월별 순차 집계 → 우리는 투구 단위로 더 촘촘히)

**Ablation 관찰**: 피처를 더할수록 **AUC는 오르지만 LogLoss는 개선되지 않음** → 순위 능력은 늘고 확률 보정은 나빠지는 과적합 경향. Optuna 40 trials로 일부 회수(0.5734).

## F · CS/W 분해 (가장 효과적)
```
P(CSW) = P(swing)·P(whiff|swing) + (1−P(swing))·P(called|take)
```
세 모델을 따로 학습(모두 엄격 투구 전 피처) 후 결합.

| | 기본 파라미터 | Optuna 튜닝 |
|---|---|---|
| 단일 `is_csw` | 0.5842 | 0.5736 |
| **분해 결합** | **0.5774** | **0.5722** |
| 앙상블 | 0.5767 | 0.5722 |

→ **분해가 단일을 일관되게 이긴다.** 두 메커니즘(타자 지켜봄 판단 vs 구위·컨택)이 섞이지 않아 학습이 선명해진 것.

## 종합 판단
- 이번 라운드로 **0.5760 → 0.5722**까지 왔고, 방향(분해 + 튜닝)은 옳았다.
- 다만 **count-only 대비 −0.0068**로 절대 이득은 여전히 작다. D의 천장 진단이 그 이유를 설명한다 — 위치를 모르는 한 AUC 0.63~0.64가 현실적 상한.
- **더 짜낼 여지**: 분해 모델별 개별 튜닝, 확률 보정(isotonic), 투수별 부분 풀링, 위치(존 통과 확률) 예측 stacking.
- **근본적 전환이 필요하면**: (a) xCSW = 현재 투구 정보로 *투구 품질 평가*(AUC 0.756), (b) 경기단위 CSW% 직접 모델링(이동평균 R² 0.244 이기기).
