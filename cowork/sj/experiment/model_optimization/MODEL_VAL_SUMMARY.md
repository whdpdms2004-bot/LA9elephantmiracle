# 모델링 Val 성능 요약

## 검증 기준

- **Val2024**: 2023년까지 학습 → 2024년 검증. TrackMan도 2023년까지만 사용
- **Val2023**: 2022년까지 학습 → 2023년 검증. TrackMan도 2022년까지만 사용
- TrackMan 투수 표현은 **해당 시즌 500구 이상 투수**만 개별화
- **BSS는 높을수록 좋고**, `ΔBrier`는 기준 모델 대비 **음수일수록 개선**
- 표의 Val2023/Val2024 ΔBrier는 전체 행 기준이다. R만 분리하면 기존 correction의 Val2023 ΔBrier는 `+0.000035`로 악화되어, 이후에는 R 양 검증 성능을 별도 기록한다.

## 핵심 해석

- 가장 큰 상승은 **단일 모델 거대화**보다 `시간 OOF 앙상블 → 상성 보정 → reverse 전용 군집/임베딩` 순서에서 발생했다.
- 트리 크기는 18 leaves에서 20~24 leaves까지는 소폭 개선됐지만, 32~128 leaves에서는 BSS가 계속 하락했다. 따라서 큰 모델은 **단독 주력**보다 **잔차가 다른 expert**로 섞는 편이 효과적이었다.
- 투수·타자 ID/군집을 XGBoost에 직접 넣는 방식은 748.96~761.01로 낮았다. 반면 **과거 정보로 만든 확률 보정값**을 기존 예측에 얹는 방식은 806~815까지 개선됐다.
- 현재 내부 Val2024 최고는 공동 SVD 공격형 `815.083`이지만 Val2023 개선폭이 작다. **안정성 기준 후보는 공동 SVD 안정형 `814.291`**, 검증된 제출 기준은 `submit_013`이다.
- 최종 2025 추론 모델은 검증 설계를 확정한 뒤 **2024년까지 전부 재학습**한다.
