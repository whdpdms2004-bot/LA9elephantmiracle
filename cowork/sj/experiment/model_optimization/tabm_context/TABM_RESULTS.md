# TabM 시간 검증 결과

최종 업데이트: 2026-08-13

## 결론

- TabM 단독으로 기존 트리 앙상블을 교체하지 않는다.
- R의 최선 TabM 구조는 `BASE43`, `k=32`, `d_block=512`, 3 blocks, 직접 Brier loss다.
- raw 투수·타자 ID(T2), 수치 임베딩, `d=768/4 blocks`는 시간 이동 성능이 나빠 제외했다.
- strict-prior 투수 성공·middle·reverse·outside residual(T3)은 단독 점수보다 예측 다양성이 유효했다.
- R 동결 조합은 `T0 2-seed 평균 80% + T3 20%`다. 선택은 Val2022·Val2023에서 끝냈고 Val2024에는 그대로 이전했다.
- F는 2023 월별 순차 OOF에서 기존 전문가 70% + TabM 30%를 선택했다. 이 비율을 Val2024에 그대로 이전해 F BSS가 `507.640 → 540.543`으로 상승했다.

## 핵심 인사이트

1. **R/F 체제 분리가 필수다.** R TabM은 2022·2023에 안정적이었지만 pooled 모델은 2023 F 성공률 급락(`0.709 → 0.473`)을 따라가지 못했다.
2. **모델 크기는 중간 구간이 최적이다.** k32-d512는 k16-d384보다 양 fold에서 소폭 개선했지만 d768-4층은 평균 BSS가 `566.9`로 하락했다.
3. **평가식과 같은 Brier loss가 유효하다.** 큰 T0에서 hybrid 평균 `586.1`보다 직접 Brier 평균 `589.7`이 높았다.
4. **raw ID는 위험하다.** T2는 Val2022를 올렸지만 Val2023을 `423.8`로 떨어뜨렸다. 선수 자체보다 시간 안전 residual/상황 반응이 낫다.
5. **T3는 다양성에 가치가 있다.** T0와 T3의 예측 상관은 약 `0.94~0.95`로, T0 seed 간 상관보다 낮다. 20%만 섞어 두 선택 fold와 2024 게이트를 모두 개선했다.
6. **F TabM도 단독보다 혼합이 낫다.** 2023의 네 월별 fold에서 30%가 선택됐고, Val2024를 보지 않고 이전해 F BSS `+32.90`을 얻었다.

## 누수·TrackMan 규약

- Val2022/2023 모델 선택에는 각 fold 이전 시즌만 사용했다.
- T3의 cutoff `S` 프로필은 `season < S`만 집계한다.
- middle·reverse·outside는 독립 성분으로 보존하며 middle/reverse 교집합을 제거하지 않는다.
- TabM Val2024 게이트에는 TrackMan을 전혀 사용하지 않았다.
- 최종 `submit_019`의 새 TabM도 TrackMan을 사용하지 않는다. 기반 017의 기존 TrackMan 경로만 strict-as-of, 투수-시즌 500구 이상 규칙을 유지한다.
