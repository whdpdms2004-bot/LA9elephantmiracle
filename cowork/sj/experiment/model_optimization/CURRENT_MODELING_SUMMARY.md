# 현재 데이터 분석·모델링 요약

## 1. 용어와 검증 기준

| 표기 | 의미 |
|---|---|
| `Val2023` | 2022년까지 학습하고 2023년 데이터로 검증 |
| `Val2024` | 2023년까지 학습하고 2024년 데이터로 검증 |
| `game_type=R` | 전체 데이터의 약 88~90%를 차지하는 다수 경기 유형 |
| `game_type=F` | 전체 데이터의 약 10~12%를 차지하는 소수 경기 유형 |

`Val2023/Val2024`의 `Val`은 검증 연도를 뜻하며, `game_type=F`와 관계없다. TrackMan은 각 검증연도보다 이전 시즌만 사용하고, 투수-시즌 500구 이상일 때만 개별 표현을 만든다.

## 2. R/F 데이터 분포

| 시즌 | R 행 수 | R 비중 | R 성공률 | F 행 수 | F 비중 | F 성공률 |
|---:|---:|---:|---:|---:|---:|---:|
| 2022 | 217,024 | 87.70% | 50.37% | 30,448 | 12.30% | 70.87% |
| 2023 | 219,839 | 89.54% | 50.31% | 25,686 | 10.46% | 47.29% |
| 2024 | 223,497 | **88.16%** | 48.97% | 30,010 | 11.84% | 45.93% |

핵심 해석:

- 전체 점수의 중심은 모수가 큰 **R**이다.
- F는 2022→2023에 성공률이 70.87%에서 47.29%로 급락한 구조적 단절이 있다.
- F를 별도 주 모델로 만들기보다 기존 모델 안에서 강하게 축소된 보조 보정으로 다루는 편이 안전하다.

## 3. R 실패 유형 변화

| 시즌 | reverse | middle | outside-only |
|---:|---:|---:|---:|
| 2022 | 25.86% | 15.24% | 12.69% |
| 2023 | 25.07% | 15.77% | 12.29% |
| 2024 | **24.27%** | **17.85%** | 12.14% |

2023→2024 R 성공률은 1.34%p 하락했지만 reverse는 0.80%p 감소하고 middle은 2.08%p 증가했다. 따라서 **R의 최근 악화는 reverse보다 middle 증가와 더 가깝다.**

## 5. `submit_013` R/F 성능 분해

아래 R/F BSS는 각 집단 성공률을 기준으로 계산한 진단용 점수다.

| 2024 모델 | 전체 BSS | R BSS | F BSS | R 평균오차 | F 평균오차 |
|---|---:|---:|---:|---:|---:|
| adjusted 단일 | 784.557 | 784.625 | 457.969 | +0.443%p | +1.015%p |
| `submit_007` | 801.147 | 806.073 | 438.213 | +0.437%p | +1.012%p |
| `submit_013` | **812.704** | **812.655** | **487.087** | +0.224%p | +0.591%p |

| `submit_007 → submit_013` | 표본 비중 | 집단 ΔBrier | 전체 개선 기여율 |
|---|---:|---:|---:|
| R | 88.16% | -0.000016 | **50.23%** |
| F | 11.84% | -0.000121 | **49.77%** |

`submit_013`은 R에서도 개선됐다. 다만 F는 행당 개선폭이 R보다 약 7.5배 커, 11.84%의 표본으로 전체 상승의 절반을 만들었다.

## 6. 검증 안정성 해석 수정

기존 correction을 adjusted 단일 모델과 비교한 결과다.

| 검증 | 집단 | ΔBrier | 판단 |
|---|---|---:|---|
| Val2023 | R | **+0.000035** | 악화 |
| Val2023 | F | **-0.000438** | 큰 개선 |
| Val2023 | 전체 | -0.000014 | F 효과로 평균 개선 |
| Val2024 | R | -0.000022 | 개선 |
| Val2024 | F | -0.000145 | 개선 |
| Val2024 | 전체 | -0.000037 | 개선 |

따라서 기존의 “Val2023·Val2024 전체 동시 개선”만으로 R에서도 안정적이라고 판단하면 안 된다. 이후 후보는 **R의 Val2023와 Val2024가 모두 개선되는지** 별도로 확인한다.

## 7. 확인된 모델링 인사이트

| 항목 | 결론 |
|---|---|
| 누적 이력 | rate만 쓰지 않고 표본 수, smoothing, 최근성, cold-start를 함께 사용해야 한다. |
| smoothing | 중간 강도인 200 부근이 가장 좋았고 과도한 수축은 성능이 하락했다. |
| TrackMan | 안정적인 저차원 요약은 유효하지만 세부 구종 확장은 악화됐다. |
| TrackMan 가용성 | 가용 투수에 경력 편향이 있어 별도 모델 분리보다 availability 피처가 안전하다. |
| 군집 | hard cluster ID 직접 입력은 실패했고 상성 통계의 smoothing 단위로 사용할 때 효과가 있었다. |
| reverse | 전체 데이터에서는 강한 보조 신호지만 R의 최근 악화를 단독으로 설명하지 못한다. |
| 공동 SVD | 기존 reverse correction과 상관이 낮아 앙상블 다양성이 좋지만 R/F별 안정성 검증이 남아 있다. |
| 모델 크기 | 20~24 leaves까지는 소폭 개선됐지만 32~128 leaves는 명확히 과적합했다. |
| 앙상블 | 단일 거대 모델보다 서로 다른 잔차를 가진 모델을 시간 OOF로 혼합하는 방식이 효과적이었다. |
| calibration | 예측 평균의 작은 편향도 BSS 손실이 커 계층적이고 강하게 축소된 보정이 필요하다. |

## 11. 전처리 감사에서 추가 확인된 사항

| 발견 | 영향 | 조치 |
|---|---|---|
| 메인 데이터 논리 범위 위반 0건 | 학습 행 삭제 불필요 | rate는 삭제·clip보다 smoothing 사용 |
| TrackMan 극단 측정값 약 0.01~0.32% | 투수별 mean/std가 일부 흔들릴 수 있음 | 과거 기준 metric별 winsorization 실험 |
| 임베딩 217차원 vs 투수 49~169명 | 군집이 소수 극단값과 seed에 민감 | compact feature·missing indicator 우선 |
| Val2023용 저장 프로필의 component 결측 86.19% | 기존 투수 군집 안정성 검증 왜곡 가능 | clean profile v2로 Val2023·Val2024 재실행 |

세부 내용은 `PREPROCESSING_REVIEW.md`에 기록했다. 공동 SVD는 저장 투수 프로필이 아니라 메인 failure label을 직접 사용하므로 캐시 결측의 직접 영향은 없다.

## 13. R/F 분기와 F 부분 풀링 전문가

| 구성 | R 처리 | F 처리 | 2023 순차 F BSS | Val2024 F BSS | Val2024 전체 BSS |
|---|---|---|---:|---:|---:|
| `submit_015` | 기존 모델 + R 문맥 | 기존 전체 모델 | - | 기준 | 830.523 |
| `submit_017` | 015와 동일 | 글로벌 0.66 + XGB 0.15 + CAT 0.19 | 128.242 | 507.640 | **833.329 추정** |
| `submit_016` | 대형 XGB + R 문맥 | 기존 전체 모델 | - | 기준 | 831.321 |
| `submit_018` | 016과 동일 | 글로벌 0.66 + XGB 0.15 + CAT 0.19 | 128.242 | 507.640 | **834.127 추정** |

R/F 완전 분리는 채택하지 않았다. R 전용 XGBoost·CatBoost는 Val2024에서 글로벌 모델보다 낮았고, F는 2023의 분포 단절 때문에 과거 전체 학습 모델이 불안정했다. 따라서 `game_type` 트리거는 유지하되 F 전문가 잔차만 축소 반영했다.

## 14. 진행 중인 고연산 캠페인

`middle` 실패 유형 이진 전문가를 Val2022·Val2023 강건 목적함수로 150회 탐색 중이다. 완료 후 상위 8개만 Val2024에 게이트하고, 같은 방식으로 reverse 120회와 outside 100회를 자동 실행한다. 각 전문가는 성공 확률을 직접 대체하지 않고 후속 OOF 스태킹의 잔차 입력으로 사용한다.
