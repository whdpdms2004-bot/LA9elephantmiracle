# 데이터·모델링 핵심 인사이트

## 한눈에 보는 결론

| 영역 | 확인된 인사이트 | 근거 | 모델링 반영 |
|---|---|---|---|
| 검증 | 무작위 분할보다 **연도 순방향 검증**이 필수 | 성공률이 2019년 56.47% → 2024년 48.61%로 하락 | Val2023=`≤2022→2023`, Val2024=`≤2023→2024` 사용 |
| 확률 기준선 | 순위력뿐 아니라 **예측 평균의 연도별 편향**이 큰 손실 원인 | 2024 예측 평균이 실제보다 약 0.76%p 높았고 oracle 보정 시 BSS +22.88 | 최근 시즌 가중, 작은 logit 보정, Brier 기준 최적화 |
| 실패 유형 | 전체에서는 **reverse가 강한 반복 신호**지만 R의 최근 악화는 middle 중심 | 전체 reverse는 증가했지만 R은 2023→2024 reverse -0.80%p, middle +2.08%p | reverse 보정을 유지하되 R 전용 middle residual 추가 |
| 실패 유형 모델 | 다중분류로 success를 직접 대체하면 손해 | failure softmax BSS 732.43, binary blend는 개선 | 실패 유형은 주 모델이 아니라 auxiliary/expert로 사용 |
| 누적 이력 | 누적률 값만큼 **표본 수와 최근성**이 중요 | smoothing 200이 최적, 너무 작거나 크면 하락 | rate + `log1p(n)` + shrinkage + cold-start flag |
| 최근 폼 | 최근 1경기는 시끄럽고 3·5경기는 비선형 신호 | 최근 1경기 delta 표준편차 12.45%p | momentum/slump 분리, shrinkage 및 분위화 |
| 경기 상황 | 개별 변수보다 **상호작용**이 중요 | 3-2, 투수·타자 손 조합, 후반 이닝에서 오차 집중 | count×hand×season×game type 상호작용 및 제한적 보정 |
| `game_type=F` | 2023년에 구조적 단절 발생 | F 성공률 70.87% → 47.29%, reverse 4.82% → 29.96% | game type을 고정 효과로 과신하지 않고 최근 시즌과 결합 |
| TrackMan | 유효하지만 가용성에 선택 편향이 큼 | 2024 가용률 60.24%, 가용 투수는 경력 투구 수가 훨씬 많음 | 별도 gated 모델 대신 availability·season gap·confidence를 함께 입력 |
| TrackMan 범위 | 세부 구종 확장보다 **안정적인 저차원 요약**이 우수 | 전체 요약 768.12~769.69, 구종별 확장 760.71~764.94 | 투수-시즌 500구 이상, compact/정규화 표현 사용 |
| TrackMan 변화 | 2022년 전후 측정·분류 체계 변화 가능성 | 동일 투수에서도 extension·구종 비중이 크게 변함 | 원시 절대값보다 시즌·구종 내 z-score와 변화량 사용 |
| 군집 | 군집 ID를 직접 넣는 것은 효과가 없음 | 직접 입력 BSS 748.96~761.01 | 군집은 상성 통계의 smoothing 계층으로만 사용 |
| 투수×타자 상성 | 전체 성공률보다 **reverse 전용 상성**이 강함 | reverse 군집 보정 후 Val2024 BSS 810.26, seed 평균 812.70 | 투수 유형×타자 유형 reverse residual을 Ridge로 보정 |
| 공동 임베딩 | 투수·타자를 함께 학습한 SVD가 기존 군집과 상보적 | 기존 reverse correction과 상관 약 0.09, Val2024 최고 815.08 | unit-normalized joint SVD + 좌우별 군집 + residual correction |
| 모델 크기 | 트리를 크게 만드는 것만으로는 과적합 | 20 leaves 785.47, 32→128 leaves는 780.80→726.37 | 20~24 leaves를 유지하고 큰 모델은 앙상블 expert로만 활용 |
| 앙상블 | 단일 모델 교체보다 **다른 잔차를 가진 모델 혼합**이 효과적 | OOF 789.67 → 상성·reverse·SVD 결합 815.08 | 시간 OOF 기반 가중치와 확률 보정 사용 |
| R/F 분해 | 전체 rolling 개선을 R 안정성으로 해석하면 안 됨 | 2023 correction은 R ΔBrier +0.000035, F -0.000438 | 채택 조건에 R의 Val2023·Val2024 동시 개선을 별도 추가 |

## 실패하거나 주의할 접근

- 전체 temporal target encoding은 최근 분포 변화에 과적합해 크게 실패했다.
- TrackMan 가용/미가용 별도 모델은 표본 분할과 선택 편향 때문에 성능이 하락했다.
- hard cluster ID, 큰 K, 타자 GMM은 희소 군집과 seed 불안정성을 키웠다.
- 테스트 데이터 전체를 이용한 재군집·통계 갱신은 누수 및 batch 의존 위험이 있으므로 사용하지 않는다.
- Val2024 단일 점수만 최대화하면 연도 특화가 될 수 있어 Val2023·Val2024의 개선 방향을 함께 확인해야 한다.
- R이 2024의 88.16%이므로 전체 개선뿐 아니라 R-only 성능을 반드시 기록한다. `submit_007→013` 개선 기여율은 R 50.23%, F 49.77%였다.

## 현재 판단

- **검증 최고점:** 공동 SVD 공격형, Val2024 BSS **815.083**
- **시즌 안정성 우선:** 공동 SVD 안정형, Val2024 BSS **814.291**
- **Public 검증 안전본:** `submit_013`, Val **812.704**, Public **895.404**
- **R 중심 다음 과제:** reverse 확대보다 middle residual과 볼카운트 보정 우선
- 최종 2025 모델은 설계를 확정한 뒤 2024년까지 재학습하되, 모든 파생 통계와 임베딩은 투구 직전 정보만 사용한다.
