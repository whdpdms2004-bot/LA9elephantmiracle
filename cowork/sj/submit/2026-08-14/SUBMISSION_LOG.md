## submit_024.zip — 플래툰 성분 결합

`submit_022`(reverse scale 0.475, offset 없음)에 성분 분해 계층을 추가했다.

```
024 − 022 = 플래툰 성분 결합 효과
023 − 022 = logit offset 효과
```

같은 기준점에서 두 축이 각각 분리된다.

| SHA256 | `2275A1E03B1F894FE77665BF2EED04986EE6859FB9E8F70EABCFF6E716495BAC` |

### 설계

```
P(success) = 1 − [ p_middle + p_reverse − p_middle∧reverse + p_outside ]
p_final    = 0.20 · P(success) + 0.80 · p_022      (game_type == "R" 행만)
```

- **포함배제**를 쓴다. 독립 가정(`(1−p_m)(1−p_r)−p_o`)은 조건부 독립이 깨져서 기각했다 — Val2024 모델 잔차 상관 −0.0657
- **R 행에만** 적용한다. 전체 적용 시 F가 −8.01 손해 (2023 레짐 붕괴로 성분 모델도 동반 붕괴)
- **w=0.20은 검증에서 고르지 않았다.** fold 간 w 전이 실패를 3회 관측해 보수값으로 고정. 2024 argmax는 0.25다

### 성분 라벨 (학습 전용)

```
누적카운트(i) = asof_rate(i) × asof_pitcher_n(i)
label(i)      = 누적카운트(i+1) − 누적카운트(i) ∈ {0,1}      # 같은 투수 연속 행
OUTSIDE       = 실패 ∧ ¬middle ∧ ¬reverse
```

`train.csv`의 공식 제공 `asof_*` 컬럼만 사용. 1,473,508행에서 복원 `success`가 실제 `control_success`와 **100.0000% 일치**, 불일치 0건. 검증 8항목은 [`claude/12_IDEA_REGISTRY.md`](../../claude/12_IDEA_REGISTRY.md) 참고.

**추론 경로에는 라벨이 들어가지 않는다.** `script.py`에 `y_middle`/`y_reverse` 문자열이 없음을 스캔으로 확인했다. 성분은 투구 이전 피처 97개로만 예측된다. `RULES.md` §10-E 선결조건 해소.

### 플래툰 스플릿 (팀통합 §1-1)

```
split(p,h) = EB(투수 p, 타자손 h) − EB(투수 p 전체),  EB = (성공수 + K·리그평균)/(표본수 + K)
K = 300,  리그평균 = 0.52376598,  lookup 1,571행 (2019~2024)
```

주효과 차감이 핵심 — 안 빼면 `asof_pitcher_success_rate`와 중복이다. `pitcher_id` 정적 조인이라 test 행 간 참조가 없다.
