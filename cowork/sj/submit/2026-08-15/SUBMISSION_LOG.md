## ⚠️ 먼저 읽을 것 — `submit_027`·`028`·`029`는 제출하지 말 것

이 세 패키지는 **검증한 구성을 구현하고 있지 않다.** 빌드 결함이다.

빌드는 이전 ZIP의 `script.py`에 성분 블록을 주입하는 방식인데, 훅 지점으로 쓴 줄이 주입 후에도 남아서 다음 빌드가 또 앞에 끼워 넣었다.

```

submit_026   정의 1 / 훅 1    904줄   정상
submit_027   정의 2 / 훅 2   1037줄
submit_028   정의 3 / 훅 3   1183줄

submit_030   정의 1 / 훅 1    942줄   정상 (재빌드)
```

Python은 마지막 정의를 쓰므로 피처 구성은 맞다. **문제는 혼합이 연쇄로 적용되는 것이다.**

```
q_k = w·p_ie + (1−w)·q_{k−1}   ⇒   q_k = (1−(1−w)^k)·p_ie + (1−w)^k·b
w = 0.25  →  w_eff = 0.4375(027) / 0.5781(028) / 0.6836(029)
```
