## 보정 분산 점검 (smoothing vs sharpening)

`a* = Cov(p,y)/Var(p)` 기준.

| 대상 | a* | 투수 블록 95% CI | LOMO ΔBSS | 개선 월 |
|---|---:|---|---:|:---:|
| 전체 | 1.047 | [0.975, 1.108] | **-2.52** | 4/8 |
| R | 1.030 | [0.948, 1.091] | **-3.52** | 3/8 |
| F | 1.285 | [0.991, 1.542] | **+16.92** | 6/8 |

LOMO = 월 하나를 빼고 7개월로 a를 적합해 뺀 월에 적용. 전체·R은 정직하게 적합하면 **악화**하므로 smoothing도 sharpening도 적용하지 않는다. 10분위 reliability에서 9개 구간 gap이 ±0.007 이내이고, `a*>1` 신호는 최상위 분위(pred 0.566 → obs 0.581) 한 칸에서 나온다.

시스템별 a*: 013 = 1.073, 019 = 1.044, 021 = 1.049, 022 = 1.047. **R context + F expert residual 추가가 이미 sharpening 역할을 했다.**

**F만 예외**: a* = 1.285, LOMO에서 F BSS +16.92 = 전체 BSS +1.99. 원인은 F expert의 partial pooling(기준 0.462 + XGB 0.105 + Cat 0.133 + TabM 0.30) 과축소다. 다만 CI가 1.0을 아슬아슬하게 포함하고, 현행 F 가중치는 2023 월별 OOF에서 선택해 2024로 이전한 값이라 2024 재조정은 프로토콜 위반이다. **다음 실험 1순위로 보류.**

## offset 근거

학습 데이터 연도별 `control_success` 평균:

| 시즌 | 성공률 |
|---:|---:|
| 2019 | 0.5647 |
| 2020 | 0.5327 |
| 2021 | 0.5328 |
| 2022 | 0.5289 |
| 2023 | 0.5000 |
| 2024 | 0.4861 |

2025 목표 성공률은 **0.4792**로 고정한다. 2024년 0.4861에서 최근 연간 하락폭의 50%를 추가 반영한 값이다.

```
2023 -> 2024 실측 변화 = -1.386%p
그 50%                 = -0.693%p
0.48610 - 0.00693      =  0.47917  ->  0.4792
```

reference rate 0.4861 → 목표 0.4792의 고정 logit offset:

```
logit(0.4861) = -0.0556143299
logit(0.4792) = -0.0832480441
offset        = -0.0276337141
```

세 값 모두 배정밀도로 재계산해 제시값과 일치함을 확인했다.

**2025 평가 데이터의 분포·예측 평균을 이용한 재계산이나 재보정은 수행하지 않는다.** 2019~2024에서 사전 결정한 상수를 추론 시 그대로 적용한다.

## 구현

`script.py` 최종 예측 직후, 유효성 검사 직전에 삽입한다.

```python
offset = float(metadata.get("season_logit_offset", 0.0))
if offset != 0.0:
    bounded = np.clip(prediction, 1e-7, 1.0 - 1e-7)
    prediction = 1.0 / (
        1.0 + np.exp(-(np.log(bounded / (1.0 - bounded)) + offset))
    )
```

값은 `metadata.json`에서 읽으므로 코드 수정 없이 조정 가능하다. `script.py`의 모든 주석과 docstring을 제거했다 (`#` 문자 0개, docstring 0개, 782줄 → 784줄).
