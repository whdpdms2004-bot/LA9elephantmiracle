# 3WAY 실험 계획

> ## ★ 2026-08-19 판정 프레임 — 앙상블은 모델링 뒤로
>
> **앙상블은 취소가 아니라 순서의 문제다.** 모델링 실험이 끝나면
> **조합별로 반드시 해야 하는 단계**다. 다만 전처리와 피처 엔지니어링을 다시 했으므로
> **모델 실험이 아직 충분하지 않다.** 그 전에 앙상블로 판정하면 순서가 뒤집힌다.
>
> | 판정 항목 | 모델링 단계 (지금) | 앙상블 단계 (나중) |
> |---|---|---|
> | 주 지표 | **단독 `bss_centered`** | 결합 ΔBSS |
> | base 와의 상관 | 보지 않는다 | 채택 조건 |
> | 블렌드 가중치 `w` | 적용 안 함 | 구간별 탐색 |
>
> 단독 기준 현재 순위 (fold 2024, `bss_centered`)
>
> | 모델 | 단독 |
> |---|---:|
> | **3WAY M+R+O identity** | **840.23** |
> | 프로덕션 base | 836.51 |
> | 1WAY 성분 라인 | 757.24 |
>
> **V65·V66 의 "정확도가 아니라 비상관성" 원리는 앙상블 단계의 규칙이다.**
> 모델링 단계에서 단독 모델을 고를 때는 쓰지 않는다. 앙상블 단계에서 되살린다.
>
> **성능을 올린 요소를 중심으로 본다.** 조합 이득보다 무엇이 실제로 예측을 개선했는가.


> 1WAY 에서 쌓은 실험 방식을 하위 확률별로 다시 적용한다.
> 이미 닫힌 축은 다시 열지 않는다 ([24_APPROACH_TYPOLOGY.md](../claude/24_APPROACH_TYPOLOGY.md) 참조).

## 어떤 방식을 가져오고 무엇을 버리는가

1WAY 유형화 9종 중, 3WAY 에서 **다시 해야 하는 것**과 **이미 닫힌 것**을 가른다.

| 유형 | 1WAY 결론 | 3WAY 에서 |
|---|---|---|
| 1. Y를 바꾸면 | 성분 분해 = +66 의 원천 | **3WAY 자체가 이 유형의 확장이다** |
| 2. 피처를 더하면 | base 가 안 가진 각도인가가 기준 | **타깃마다 다시** ← S1·S2 |
| 3. 피처를 빼면 (계층 차감) | 최대 발견. 조건 둘 필요 | **타깃마다 축이 다를 수 있다** ← S3 |
| 4. 모델을 바꾸면 | GBDT 를 못 넘음 | **버린다** |
| 5. 학습 방식 | 버리지 말고 가중치를 낮춰라 | **타깃마다 기저율이 달라 재확인 필요** ← S4 |
| 6. 합치는 법 | 구조적 질문만 통함 (Public +15) | **3WAY 의 핵심** ← S5 |
| 7. 사후 보정 | 5전 1승, 최악 −162 | **버린다** |
| 8. 쪼개면 | 전부 실패 | **버린다** |
| 9. 측정을 의심하면 | fold 2개가 못 쓰는 것이었다 | **이미 반영** (harness3) |

## 단계

### S1. 타깃별 전처리 단일 스크리닝 ← 진행 중

전처리 원자 15종을 타깃마다 하나씩. `preprocess_lab` 레지스트리 재사용.

```bash
python src/screen_target.py --target middle,reverse,ball
```

**핵심 질문**: 타깃마다 맞는 전처리가 다른가?
- 다르면 3WAY 의 전제가 성립한다
- 같으면 1WAY 대비 이득이 결합 단계에서만 나온다

**참고**: 1WAY(success) 에서는 `id_frequency +7.94`, `temporal_cyclic +4.75`,
`trackman_quality −3.11` 이었다. 타깃별로 이 순위가 뒤집히는지가 관전 포인트다.

소요: 타깃당 약 12분 (16 arm × 45s)

---

### S2. 타깃별 조합 빔 서치

S1 상위 3개에서 시작해 조합을 넓힌다.

```bash
python src/screen_target.py --target middle --beam 3 --rounds 3
```

**1WAY 에서 배운 것을 그대로 적용한다**:
- 단독 성능으로 거르지 않는다 (`trackman_quality` 단독 −3.11 인데 최고 조합 필수)
- 다 켜지 않는다 (`all_compact` 가 최선 단일보다 5점 낮았다)
- 넓은 구간에서 통과해야 채택

소요: 타깃당 약 40분

---

### S3. 타깃별 계층 차감 축

1WAY 의 최대 발견을 타깃마다 다시 건다.

```
split(투수, 타자손, 축) = EB(투수, 타자손, 축) − EB(투수, 타자손)
```

**타깃마다 맞는 축이 다를 것으로 본다.**
- `middle` 은 카운트 의존이 클 것 (3-0 에서 한가운데를 던져야 한다)
- `ball` 은 카운트 의존이 가장 클 것 (0-2 에서 유인구)
- `reverse` 는 타자손 의존이 클 것

1WAY 는 다섯 성분에 **같은 축 네 개**를 걸었다. 여기서 갈리는지 본다.

성립 조건 둘을 반드시 확인 ([METHOD.md](../preprocess_lab/METHOD.md)):
ㄱ 중복이 실재하는가 · ㄴ 두 항이 같은 단위인가
그리고 셀 크기 관문 (한 행 기여 `1/(n+K)` < 1%)

---

### S4. 타깃별 학습 방식

1WAY 에서 통한 셋을 타깃마다 재확인한다. **기저율이 0.15~0.37 로 달라 그대로 옮겨지지 않을 수 있다.**

| 항목 | 1WAY 결과 |
|---|---|
| F행 가중치 0.20 | +4.07 |
| 짧은 등판 가중치 0.5 | Public +4 |
| 기저율별 트리 파라미터 | +0.91 |

**닫힌 것은 하지 않는다**: 학습 방식 40 arm 스윕(V72)은 0/40 이었다.

---

### S5. 결합 + 최종 라벨 미세조정 ★ 3WAY 의 핵심

```
[middle] [reverse] [ball]  →  결합기  →  P(성공)
                                 ↑ 최종 라벨로 미세조정
```

**비교할 것**

| 구성 | 왜 |
|---|---|
| M/R/B | 지시받은 구성 |
| M/R/O | 항등식이 닫힌다 (실패 = m ∪ r ∪ o, 오차 0) |
| M/R/B/O | 넷 다 |
| 1WAY 5성분 | 기준선 |

**결합기 후보**
1. 로지스틱 (선형) — 해석 가능, 과적합 적음
2. 얕은 GBDT — 상호작용 허용
3. 포함–배제 항등식 + 잔차 학습 — 1WAY 구조 위에 보정

**판정**: `bss_centered` on fold 2024, 보조 fold 2023.
그리고 **base 와의 상관** — 1WAY 대비 내려가는지가 3WAY 의 존재 이유다.

---

### S6. 1WAY 와 정면 비교

같은 fold, 같은 base 위에서 결합 ΔBSS 를 견준다.
**3WAY 가 이기려면 base 와의 상관이 1WAY(0.8219)보다 낮아야 한다.**
정확도만 높고 상관이 같으면 결합에서 못 이긴다 (V65·V66 이 양방향으로 확인한 원리).
