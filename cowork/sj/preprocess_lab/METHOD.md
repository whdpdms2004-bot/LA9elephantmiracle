# 실험 방식 — 전처리를 어떻게 재는가

> ## ★ 2026-08-19 판정 프레임 — 앙상블은 모델링 뒤로
>
> **앙상블은 취소가 아니라 순서의 문제다.** 모델링 실험이 끝나면
> **조합별로 반드시 해야 하는 단계**다. 다만 전처리와 피처 엔지니어링을 다시 했으므로
> **모델 실험이 아직 충분하지 않다.** 그 전에 앙상블로 판정하면 순서가 뒤집힌다.
>
> | 판정 항목 | 모델링 단계 (지금) | 앙상블 단계 (나중) |
> |---|---|---|
> | 주 지표 | **단독 `bss_centered`** | 결합 ΔBSS |
> | base 와의 상관 | 보지 않는다 | 채택 조건 |
> | 블렌드 가중치 `w` | 적용 안 함 | 구간별 탐색 |
>
> 단독 기준 현재 순위 (fold 2024, `bss_centered`)
>
> | 모델 | 단독 |
> |---|---:|
> | **3WAY M+R+O identity** | **840.23** |
> | 프로덕션 base | 836.51 |
> | 1WAY 성분 라인 | 757.24 |
>
> **V65·V66 의 "정확도가 아니라 비상관성" 원리는 앙상블 단계의 규칙이다.**
> 모델링 단계에서 단독 모델을 고를 때는 쓰지 않는다. 앙상블 단계에서 되살린다.
>
> **성능을 올린 요소를 중심으로 본다.** 조합 이득보다 무엇이 실제로 예측을 개선했는가.


> 이 문서가 이 랩의 핵심이다. **결과보다 측정 방식이 더 자주 틀렸다.**
> 아래 함정 넷은 전부 실제로 밟았던 것이고, 하나는 arm 판정을 7칸 뒤집었다.

## 1. 기본 설정

| | |
|---|---|
| 모델 | CatBoost GPU (`catboost_v2r200_tm500_robust_best.json`) |
| 피처 기반 | `F1` = strict forward-OOF component hierarchy + D0 |
| 스크리닝 fold | **2024 단독** |
| 확인 fold | **2023 + 2024** (2022 는 쓰지 않는다 — §3) |
| 순위 지표 | **`bss_centered`** (§2) |
| 학습 | `season < fold` 만. 모든 통계 변환은 학습 행에서만 fit |

`BSS = 100000 × (1 − Brier / Brier_null)`. 값이 클수록 좋다.

## 2. 왜 `bss_centered` 로 순위를 매기는가 ★

```
bss_raw       예측을 그대로 채점한 BSS
bss_centered  예측 평균을 실제 평균에 맞춘 뒤의 BSS
bss_raw − bss_centered = "평균 정렬로 번 점수"
```

Brier Skill Score 는 예측 평균이 어긋나면 제곱으로 벌점을 먹는다
(대회 실측: `손실 ≈ 401,000 × (예측평균 − 실제평균)²`).
그래서 **전처리의 진짜 신호와 "우연히 평균이 잘 맞았다" 가 `bss_raw` 안에서 섞인다.**

### 실제로 판정이 뒤집힌 사례

| arm | 예측 오프셋 | Δ bss_raw | **Δ bss_centered** |
|---|---:|---:|---:|
| `temporal_cyclic` | **+0.0120** | **−17.18** (탈락) | **+4.75** (2위) |
| `id_frequency` | +0.0083 | +16.15 | +7.94 |

`temporal_cyclic` 은 예측 평균이 전 arm 중 가장 높다. 그것 하나 때문에
`bss_raw` 로는 하위권이지만, **신호만 보면 2위다.**
반대로 `id_frequency` 는 +16.15 중 **절반이 평균 정렬 이득** 이다.

> **평균 정렬로 번 점수는 다른 fold 나 리더보드로 따라가지 않는다.**
> 전처리를 고를 때는 신호만 본다.

`bss_centered` 는 검증 시즌의 실제 평균을 쓰므로 **진단용이다.**
제출 예측을 이렇게 만들 수는 없다. 순위를 매기는 데만 쓴다.

## 3. 어느 fold 를 믿는가 ★

| fold | 상태 | 쓰는 법 |
|---|---|---|
| **2024** | 신뢰 가능 | **결정 fold** |
| 2023 | 오프셋 교란 | 보조. `bss_centered` 로만 본다 |
| **2022** | **역신호** | **쓰지 않는다** |

**2022 를 빼는 이유.** 방법 17개의 fold 간 순위 상관이

| 계열 | 2022→2023 | 2023→2024 | **2022→2024** |
|---|---:|---:|---:|
| xgboost | −0.632 | +0.385 | **−0.537** |
| catboost | +0.656 | −0.241 | **−0.645** |

**두 계열 모두 2022→2024 가 음수다.** 2022 에서 잘하면 2024 에서 못한다.
가중을 낮추는 것으로 부족하다 — 실측으로, 세 fold 단순평균으로 고르면
CatBoost 에서 "보정 안 함" 을 골라 **−37.77** 을 물었다.

2022 는 학습 데이터가 가장 적은데(3시즌) AUC 가 가장 높다(0.5770 vs 2024 의 0.5503).
순서가 거꾸로다. 원인은 아직 모른다 — 밝히면 검증 fold 를 하나 되찾는다.

**2023 을 조심하는 이유.** base 예측 평균이 실제보다 +0.0224 높아 `bss_raw` 가
−140.20 인데 오프셋만 제거하면 +60.68 이다. 손실 200.88 이 전부 오프셋이다.
이 fold 의 `bss_raw` 차이는 신호가 아니라 **두 어긋난 평균의 상쇄량** 을 잰다.

## 4. 무엇 위에서 재는가 — 기준선 함정

전역 시즌 offset 을 걸고 채점한다면, **그 모델 계열의 최선 전역 offset 위에서** 재야 한다.

같은 세그먼트 보정이
- CatBoost 를 **나쁜** 기준선(`all_d025`) 위에서 재면 **+10.20**
- **최선** 기준선(`last3_d075`) 위에서 재면 **−0.38 ~ +0.54**

나쁜 기준선 위의 이득은 **전역 예보의 부족분을 대신 메운 것** 이지 새 정보가 아니다.

| 계열 | 최선 전역 offset |
|---|---|
| xgboost | `all_d100` |
| catboost | `last3_d075` |

> 이 랩의 기본값은 **offset 을 아예 걸지 않고 `bss_centered` 로 재는 것** 이다.
> 그러면 이 함정을 통째로 피한다.

## 5. 다 켜면 나빠진다

```
id_frequency 단독          +7.94
all_additive  (8개 전부)   +3.27
all_compact  (12개 전부)   +2.78
```

`all_compact` 는 `id_frequency` 를 **포함하는데도** 단독보다 5점 낮다.
전처리는 더할수록 좋아지지 않는다. **최적은 부분집합이다.**

그래서 단일 스크리닝만으로 끝내지 말고 **조합 탐색(빔 서치)** 을 돌린다.
`scripts/run_beam.py`.

## 6. 지켜야 할 제약 (어기면 제출 불가)

| | |
|---|---|
| **행 독립성** | test 행끼리의 집계·분포·순위 금지. `test.groupby`, rolling, cumsum 전부 |
| **시간 인과** | 모든 통계는 `season < fold` 에서만 fit. as-of 컬럼은 그대로 써도 됨 |
| **미래 시즌 금지** | 검증/테스트 시즌 라벨을 어떤 형태로도 참조하지 않는다 |
| **pickle/joblib 금지** | 제출 패키지에 sklearn pickle 을 넣지 않는다 |

새 전처리를 낼 때 **위 넷을 어떻게 지켰는지 한 줄로 적어달라.**

## 7. 자기 라벨 누수 — 가장 자주 터진 곳

라벨로 만든 테이블(EB 평활 등)을 피처로 넣을 때, **셀이 작으면 그 행 자신의 라벨이
값에 들어간다.** 네 번 관측했다.

| | 셀 크기 전 → 후 |
|---|---|
| V1 | 705.7 → 187.5 |
| V37 | 743.8 → 507.8 |
| V35 | 745.9 → 259.1 |
| V59 | 744.1 → 533.4 |

**판정 기준**: 중앙 셀에서 한 행의 기여분 `1/(n+K)`.
1% 초과면 경고, 3% 초과면 보류.
현행 투수×타자손이 0.144%(안전), 투수×타자 개별이 중앙 13행(붕괴)이다.
