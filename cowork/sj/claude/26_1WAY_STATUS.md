### 2-2. 전처리 재설계 결과 (2026-08-18)

1WAY(`success` 타깃) 기준 전처리 최적 조합:

```

```

| 배운 것 | 내용 |
|---|---|
| **단독으로 거르면 안 된다** | `trackman_quality` 단독 −3.11 인데 최상위 조합 전부에 포함 |
| **다 켜면 나빠진다** | `all_compact`(12개) +2.78 < `id_frequency` 단독 +7.94 |

## 4. 측정 방식에서 확립된 것 — 3WAY 가 그대로 승계

| | 내용 |
|---|---|
| **fold 2024** | 결정 fold |
| fold 2023 | 보조. `bss_centered` 로만 (오프셋 교란 +0.0224) |
| **fold 2022** | **쓰지 않는다.** 레짐이 다르다 (train/valid 사이에 단절 없음) |
| 시드 잡음 | fold2024 sd 1.37. 타깃별로 null 배율만큼 환산 |
| 순위 지표 | `bss_centered` — 평균 정렬 이득을 뺀 순수 신호 |

**fold 2022 정정 (C1, 2026-08-19)**: 이전에 "오염 의심"으로 적었으나 원인은 다르다.
`encode_fold` 는 깨끗하고, 하이퍼파라미터는 `--folds 2023,2024` 로만 탐색됐다.
**즉 fold 2022 에는 선택 누수가 없고, 오히려 fold 2023·2024 에 있다.**
2022 가 높은 것은 train/valid 사이에 레짐 단절이 없어서다.
테스트(2025)는 단절 이후라 2022 는 대표성이 없다 — 빼는 결정은 그대로 유효하다.

> **새로 드러난 것**: fold 2023·2024 의 내부 BSS 는 하이퍼파라미터 선택 누수만큼
> 낙관적이다. "내부 델타가 Public 을 못 맞춘다"의 원인 일부일 수 있다. 미측정.
