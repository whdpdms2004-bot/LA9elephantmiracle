## 0. 먼저 — 무엇이 리더보드로 전이되는가

팀 전원이 데인 지점이라 이것부터 고정한다. (팀통합 §1-5)

| 변경 종류 | 전이율 | 실측 |
|---|---|---|
| **새 피처 추가** | **40% 이하, 부호 반전도 있음** | 정희원 tm_pred_8: 검증 3/3 개선 → LB **−36.5** · 찬우 플래툰: +85 → **+32.5 (40%)** |
| **앙상블 / 배깅 / residual 적층 / 캘리브레이션** | **90% 이상** | sj `013→022` 체인 +23.5 → Public **+21.3 (90.5%)** · 예나 LGB+Cat 50:50 **+151.4** |

> 정희원 요약: *"하이퍼파라미터·앙상블처럼 **새 정보를 추가하지 않는** 변경이 가장 안전했다"*

**따라서 우선순위는 기법 > 피처다.** 아래 카탈로그도 그 순서로 읽는다.

## B. 피처 카탈로그

### B1. sj 라인 보유 (문서 13 기준 99~211개)

원본 47 + stateless 파생 + 수축 프로파일 + 최근폼 파생 + TrackMan(strict as-of) + insight drift prior + 클러스터/residual.

### B2. 팀에 있는데 sj 라인에 **없는** 것

| # | 피처 | 보유 | 실측 | 상태 |
|---|---|---|---|---|
| **F1** | **투수별 플래툰 스플릿** | **4/5명 독립 발견** | README(무명) val **755.7 → 816~819** ("전체에서 가장 큰 단일 개선") · 찬우 LB **+32.5** | ⚠️ **sj는 hand를 residual의 *축*으로만 쓴다. 투수별 스플릿 피처가 없다.** 최우선 |
| **F2** | `pitcher_team_id`/`batter_team_id` 범주형 | 정희원 | 검증 **3/3 개선**, 미실행 | 아무도 실행 안 함 |

#### F1 팀 표준 구현 (팀통합 §1-1)

```
스플릿 = EB(투수의 해당 좌우 타자 상대 성공률) − EB(투수의 전체 성공률)
EB(x)  = (성공수 + K × 리그평균) / (표본수 + K),   K = 200 (팀 통일안)
```

**주효과를 빼는 게 핵심이다.** 안 빼면 `asof_pitcher_success_rate`와 중복된다 — 찬우 실험에서 투수 주효과 단독 기여가 **정확히 0.0**이었다.

**왜 큰가.** 대회 제공 `asof_pitcher_success_rate`에 **좌우 구분이 없다.** 좌타 상대 58.4% / 우타 상대 43.2%인 투수(#23637)도 평균 0.50 하나로 뭉개진다. 15%p 정보가 통째로 사라진다.

전역 효과만 4.7%p:

| 투수손 × 타자손 | n | 성공률 |
|---|---:|---:|
| 좌 × 좌 | 170,292 | 0.4909 |
| 좌 × 우 | 211,059 | **0.5375** |
| 우 × 좌 | 525,455 | 0.5307 |
| 우 × 우 | 568,286 | 0.5221 |

**규정 처리**: train.csv에서 투수별 좌우 스플릿을 계산해 **정적 lookup**으로 만들고 test에 `pitcher_id`로 조인한다. 프로덕션의 `pitcher_lookup_2025.csv`와 같은 방식이라 test 행 간 참조가 없다.

### B3. 종결 — 사용하지 않음

| 피처 | 근거 |
|---|---|
| 선수 ID 범주형·임베딩 | **5명 전원 시도, 5명 전원 기각.** 예나 36조합 전부 악화, 정희원 SVD −41.5, 찬우 AUC 0.5166 < asof 0.5342. 다음 시즌 신규 투수 24.3~33.1% |
| TrackMan 물리 피처 | **팀 최대 시간 투입, 최대 실패.** 정희원 검증 3/3 개선 → 실LB −36.5. 매칭은 되는데 쓸모가 없다 |
| pitcher-batter 매치업 히스토리 | 예나 3/3 악화, 정희원 OOV 48.8% |
| 아웃카운트·경기중요도(LI) 축 | **sj 실측 (문서 12)**: 13개 축, LI 4종 두 fold 모두 net 음수 |
| 세트포지션(주자 유무) | 찬우 잔차검정 0.60~0.64 · sj `outs×base_state` 두 fold 음수. **독립 2건 일치** |

## C. 두 라인이 서로 확인해준 것

| 사실 | 팀 출처 | sj 실측 |
|---|---|---|
| 캘리브레이션 벌점 = `401,000 × 오차²` | 팀통합 §2-1 | Val2024 전역 편향 +1.11%p → **49 BSS**. 공식값 49.4와 일치 |
| 2023은 저표본 투수 상위 10분위가 뒤집힌다 | 찬우 십분위 분석 | Val2023 F BSS **−16,022**, 성분 모델도 동반 붕괴 |
| 노이즈보다 작은 개선은 채택 금지 | 예나 3→8시드 반전 2건, 찬우 ±38점 | Val2024 σ_abs **6.24**, `021 vs 019 = +0.64 = 0.1σ` |
| `season` 피처가 이미 부분 보정을 한다 | 찬우 (빼면 347 → −48) | drift base_score가 Val2024 **평균 불변**, σ만 −23% |

**서로 다른 방법으로 같은 결론에 도달한 항목들이라 신뢰도가 높다.** 특히 캘리브레이션 벌점 공식이 독립 실측과 소수점까지 맞은 건 두 라인의 측정이 모두 옳다는 뜻이다.

## D. 실험 조합 설계

### D0. 원칙

1. **기법 먼저, 피처 나중.** 전이율 90% vs 40%
2. **한 번에 하나씩.** 조합은 개별 검증 뒤에만
3. **선택은 2022, 부호 확인 2023, Val2024 1회 게이트.** 최종 비교는 **2019~2023 학습 → 2024 성능** 단일 기준
4. **분모는 `SE_row`(행 쌍대)와 `σ_pair`(시드 쌍대).** 절대 σ는 차이 판정에 과도한 자다

### D1. 1라운드 — 단독 검증 (각 반나절, 병렬 가능)

| # | 실험 | 대상 | 기대 근거 | 중단 조건 |
|---|---|---|---|---|
| **E1** | **플래툰 스플릿 (F1)** | K ∈ {100, 200, 300} × 주효과 차감 유무 | 4/5명 독립 발견, LB 실측 +32.5 | 주효과 차감 없이 이득 나면 중복 의심 |
| **E2** | **얕은 트리 (T5)** | `max_leaves` ∈ {6, 12, 18, 24} 단독 | 두 연도 노이즈 초과한 유일 HP | — |
| **E3** | **감쇠 외삽 (T2)** | λ ∈ {0.33, 0.4, 0.5} vs 현행 선형 | 2022·2023에서 갈린다 | 2024만으로 판단 금지 |
| **E4** | **극단 cap (T1)** | 상·하한 그리드 | 2023 방어 +800 | 정상 연도 손실 10점 이내 확인 |
| **E5** | 팀 ID 범주형 (F2) | Cat 범주형 지정 | 정희원 3/3 미실행 | — |

### D2. 2라운드 — 결합 (1라운드 통과분만)

| # | 조합 | 설계 |
|---|---|---|
| **C1** | **성분 라인 + 플래툰** | P10의 5개 타깃 모델 전부에 F1 추가. **성분별로 플래툰 효과가 다를 것** — REVERSE(포수 요구 반대)는 좌우 의존이 크고 MIDDLE은 작을 가능성 |
| **C2** | 성분 라인 + 얕은 트리 | E2 최적값을 5개 타깃에 적용 |
| **C3** | **계열 확장** (T4·T7) | 성분 모델을 XGB / LGB / Cat 3계열로. **계열 단위** 가중 |
| **C4** | 캘리브레이션 조합 | beta vs isotonic vs 없음 × 감쇠 외삽 |
| **C5** | **최종 결합** | 강한 base + 성분 라인 + cap, 가중치는 2022에서 |

### D3. 우선순위 — 왜 이 순서인가

```
1. E1 플래툰       ← 팀 최대 발견인데 sj 라인에 없다. 유일하게 LB 실측이 있는 새 피처
2. C1 성분×플래툰   ← 성분별 좌우 의존 차이는 아무도 안 본 각도
3. E2 얕은 트리     ← 싸고, 두 연도 검증된 유일 HP
4. C3 계열 확장     ← 전이율 90% 구간
5. E4 극단 cap     ← 2025 레짐 리스크 보험
6. E3 감쇠 외삽 / E5 팀 ID
```

**C1이 이 계획의 핵심 가설이다.** REVERSE는 정의상 "포수 요구 방향과 반대"라 좌우 매치업과 직결되는데, 지금까지 플래툰은 `control_success` 단일 타깃에만 붙었다. 성분별로 분해하면 플래툰 신호가 REVERSE에 집중돼 있을 가능성이 높고, 그러면 **분해가 플래툰의 효과를 증폭한다.**

sj 실측이 이 가설을 뒷받침한다 — E1a에서 `middle`–`reverse` 의존이 `count_state`(6/12 셀)와 `pitcher_id`(134/246명)에서 유의했다. 좌우는 아직 성분 단위로 안 봤다.
