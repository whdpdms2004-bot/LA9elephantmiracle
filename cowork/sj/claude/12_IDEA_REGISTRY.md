## I1 — 상황 축(아웃카운트·경기중요도) 잔차 활용

**결론 세 가지.**

1. **경기중요도(LI)는 완전히 죽었다.** 4개 LI 축 전부 두 fold 모두 음수다. 더 보지 않는다.
2. **아웃카운트 단독도 죽었다.** 살아 있는 건 좌우조합과 결합했을 때뿐이다.
3. `count × hand`가 살아난 것이 중요하다. 이 축은 **이미 R context residual로 구현돼 있는 축**이다. 진단기가 알려진 실제 신호를 검출했다는 뜻이므로 나머지 축의 "무신호" 판정을 신뢰할 수 있다.

**남은 실험 (축소된 예산, 반나절):**

- **C1**: R context residual(`count × inning × hand`)에 `outs` 축 하나만 추가.
- 채택: Val2024에서 +9.4 이상 **and** Val2022 부호 양수. 현재 net +8.4는 미달이므로 **떨어질 가능성이 높다.**
- 중단: 미달이면 상황 축 전체 종료.

## I2 — 투수별 모델링 (부분 풀링)

> "투수별 모델링... 2024 기준 몇 개 이상의 투구 수의 선수를 대상으로 할지"

**상태: 임계값 결정 완료. 본 실험 미실행.**

커버리지 EDA → [`10_PITCHER_COVERAGE.md`](10_PITCHER_COVERAGE.md)

- 2023 단일 시즌 기준: ≥100구 **71.21%** / ≥200구 **68.40%** / ≥500구 **59.20%** (상한 75.65%)
- 2019~2023 누적 기준: ≥100구 **78.48%** / ≥200구 **77.45%** / ≥500구 **73.35%** (상한 80.14%)
- **누적 500구(73.35%)가 단일 시즌 100구(71.21%)보다 넓다** → 임계는 누적으로 건다
- **cold start 19.86%** 는 개인화가 정의상 닿지 않는다. 이득 상한은 커버리지에 비례한다

**완전분리는 하지 않는다.** 자체 실험에서 이미 졌다 (0723 A라운드, LogLoss 0.5865 vs 전체 0.5760).

**실험 설계** → [`src/p3_pitcher_offset.py`](src/p3_pitcher_offset.py) (작성 완료, 실행 대기)

```
delta_p = (r_p / v_p) · n_p/(n_p + λ) · scale
p_final = sigmoid(logit(p_base) + delta_p)
```

- `r_p` = 투수 p의 **순방향 체인 OOF** 잔차 가중평균, `v_p` = p(1−p) 가중평균
- 대상: 학습 시즌 누적 ≥ T. 미달/신규는 delta=0 (base 보존)
- 그리드: T ∈ {100, 200, 500} × λ ∈ {50,200,500,1000,2000} × scale ∈ {0.25,0.5,0.75,1.0} × half_life ∈ {1, 2, ∞}
- 선택은 **2022에서만**, 2023 부호 확인, 2024는 게이트 1회
- 채택: Val2024 +9.4 이상

**가장 유력한 실패 시나리오**: `asof_pitcher_success_rate` + prior 200 smoothing + reliability가 이미 투수 절편을 흡수. 그래서 제일 싼 D1을 먼저 돌리고, 미달이면 D2(투수×상황)·D4(완전분리 재현)를 중단한다.

## I3 — 실패 유형별 모델 3개 → 합사건 확률 → end-to-end 학습

> "각 제구 실패 유형별 모델을 학습하고 그 세 확률을 통해 셋 중 하나라도 나올 확률을 최종적으로 구하는 설계. 세 확률의 합사건 확률로 구하면서 그거 기반 오차로 학습을 계속"

**상태: 전제 실측 완료. 식은 틀렸으나 고치면 성립. 규정 리스크가 착수 전 선결 조건.**

### 실측 결과 → [`src/p4_failure_structure.py`](src/p4_failure_structure.py)

같은 투수 연속 행의 asof 누적 카운트 차분으로 각 투구의 유형을 복원했다. 1,473,508행에서 **복원 success가 실제 `control_success`와 100.0000% 일치**한다.

**(1) `ball`은 실패 유형이 아니다.**

| | middle | ball | reverse |
|---|---|---|---|
| success=1 행에서 발생 | **0건** | **231,003건 (29.9%)** | **0건** |

성공 행의 조합은 `(0,0,0)` 70.07% 또는 `(0,1,0)` 29.93% 둘뿐이다. `asof_pitcher_ball_rate`의 "볼성 결과"는 **존을 벗어난 모든 공**이고, 문제 정의의 실패 조건은 "존에서 **크게** 벗어남"이다. 유인구·의도된 볼은 볼이면서 제구 성공이다.

**(2) 세 유형의 합집합은 실패와 같지 않다.**

실패 701,805행 중 — 정확히 하나 **67.27%** / 두 개 이상 **27.85%** / **하나도 없음 4.88%**

**(3) 두 공식 모두 크게 빗나간다.**

```
실제 실패율                       0.476282
배타 가정  a+b+c                  0.748189   오차 +0.272
독립 가정  1-(1-a)(1-b)(1-c)      0.586658   오차 +0.110
```

제안한 합사건 공식은 실패 확률을 **11%p 과대평가**한다.

### 그런데 올바른 세 성분으로 바꾸면 거의 정확히 맞는다

`ball` 대신 **OUTSIDE := 실패 ∧ ¬middle ∧ ¬reverse** (194,093행, 실패의 27.66%)를 쓴다. 정의상 middle·reverse와 배타다.

그리고 **middle과 reverse는 서로 거의 독립이다**: corr = **−0.0011**

```
P(m)·P(r)  = 0.149616 × 0.229043 = 0.034271
실제 P(m∧r)                      = 0.034100      차이 0.00017
```

따라서

```
P(success) = (1 − p_middle)(1 − p_reverse) − p_outside
```

수치 검증: `0.850384 × 0.770957 − 0.131730 = 0.523865` vs 실제 `0.523718` — **오차 0.000147.**

**아이디어의 구조는 맞다. 성분 선택과 결합식만 틀렸다.**

### 정식 라벨 산출 — 검증 완료

[`src/p5_failure_labels.py`](src/p5_failure_labels.py) → `cache/failure_labels.parquet`

```
누적카운트(i) = asof_rate(i) × asof_pitcher_n(i)
label(i)      = 누적카운트(i+1) − 누적카운트(i) ∈ {0, 1}      # 같은 투수 연속 행
```

| season | success | MIDDLE | REVERSE | OUTSIDE |
|---:|---:|---:|---:|---:|
| 2019 | 0.564560 | 0.125027 | 0.181454 | 0.156951 |
| 2020 | 0.532655 | 0.148182 | 0.209248 | 0.141807 |
| 2021 | 0.532712 | 0.143738 | 0.244494 | 0.119446 |
| 2022 | 0.528853 | 0.149497 | 0.232779 | 0.125401 |
| 2023 | 0.499982 | 0.153316 | 0.255821 | 0.125102 |
| 2024 | 0.486071 | **0.176292** | 0.248001 | 0.122943 |
| **2019→2024** | **−7.85%p** | **+5.13%p** | **+6.65%p** | **−3.41%p** |

**세 성분의 추세가 서로 반대다.** MIDDLE·REVERSE는 오르고 OUTSIDE는 내린다. 단일 모델은 구성비가 계속 바뀌는 혼합물을 하나의 drift로 근사해야 하지만, 성분별 모델은 각자의 drift를 가질 수 있다.

2023→2024만 보면 더 뚜렷하다: MIDDLE **+2.30%p**가 거의 전부이고 REVERSE는 오히려 **−0.78%p** 감소했다. 최근 하락의 원인이 "가운데 몰림"에 몰려 있다.

**이것이 합사건 공식과 무관하게 분해가 가치를 갖는 이유다.** 예나의 6개 방법이 실패했더라도 이 축은 다시 볼 값이 있다.

### 실험 설계

**아키텍처.** end-to-end 학습은 합성식이 미분 가능해야 한다. GBDT로는 custom objective로 억지로 가능하지만 자연스럽지 않다. **torch 신경망 3-헤드**가 맞다 (로컬 GPU·TabM 경험 보유).

```
공유 인코더 → head_m, head_r, head_o
P_success = (1 − σ(z_m))(1 − σ(z_r)) − σ(z_o)      # clip [ε, 1−ε]
L = Brier(P_success, y_success)
    + λ_aux · [ BCE(σ(z_m), y_middle) + BCE(σ(z_r), y_reverse) + BCE(σ(z_o), y_outside) ]
```

**보조 손실은 필수다.** 최종 타깃만으로 학습하면 세 헤드의 정체성이 사라지고 단일 모델을 과다 파라미터로 쓰는 것과 같아진다. 이득은 멀티태스크 정규화에서 나온다.

**단계:**

- **E1** 조건부 독립 검증 — corr(m, r)가 **행 단위 조건부**로도 0인가. 카운트·좌우·투수 구간별로 재확인. 여기서 깨지면 상호작용 항이 필요하다
- **E2** 3-헤드 없이 성분별 GBDT 3개 + 위 식으로 사후 결합 (end-to-end 없음). 기존 Outside expert 산출물 재사용 가능
- **E3** E2가 base 대비 개선이면 3-헤드 end-to-end로 확장
- **E4** λ_aux 그리드, 결합식 clip 방식

채택: Val2024 +9.4 이상. 선택은 2022, 게이트 2024 1회.

## I4 — 새 설계가 들어올 때 기존 채택 결정을 재실험한다 (원칙)

> "지금까지 설계상 맞다고 생각한 부분도 새로운 설계가 들어갈 때 계속 다시 실험해봐"

**타당하다. 오늘 실측이 근거를 준다.**

Phase A에서 세 가지가 드러났다.

1. **노이즈 σ가 한 번도 측정된 적이 없었다.** Val2024 σ=6.24. `submit_021` vs `019`의 +0.642는 0.1σ, `022` vs `021`의 −0.261은 0.04σ다. **836 구간의 세 후보는 애초에 구분 불가능했다.**
2. **시즌 drift 보정이 없었다.** 보정 전 Val2023은 BSS −397 ± 56. 2023으로 평가된 모든 과거 판단은 σ 56짜리 자로 잰 것이다.
3. **전역 편향 함정.** Val2024 base의 예측 평균이 +1.11%p 어긋나 있고 그것만으로 49 BSS다. 전역 통제군 없이 셀 오프셋을 적합한 실험은 **어떤 축이든 +43 BSS의 가짜 신호**를 낸다.

**운영 규칙:**

- 새 성분을 붙일 때마다 **기존 성분의 가중치·scale을 다시 연다.** 고정 상수로 물려받지 않는다
- 모든 비교는 시드 8회 산포를 먼저 재고 시작한다
- 셀·그룹 오프셋을 다루는 실험은 **반드시 전역 통제군**을 함께 낸다
- fold별 σ가 다르므로 채택선도 fold별로 다르다 (7.1 / 34.4 / 9.4)

## I5 — 기각한 것을 다시 본다 (원칙)

> "버렸던 것도 다시 보고"

**우선순위는 "기각 근거가 부실한 것" 순이다.** 단일 fold로 기각됐거나 노이즈를 안 재고 기각된 것부터.

| 기각 항목 | 원 근거 | 재검토 우선순위 | 이유 |
|---|---|---|---|
| **실패유형 분해** | 예나 6개 방법 전부 실패 | **1** | I3가 다른 메커니즘(합성식 + end-to-end)이다. 기존 6방법은 사후 결합으로 추정 |
| **투수 × 볼카운트** | 찬우 잔차검정 1.03 | **2** | 내 진단에서 `count × hand` net +11.7, `outs × hand` +8.4. 인접 축에 신호가 있다 |
| **로지스틱 스태킹** | "단일분할 함정, 단순평균 우위" | **3** | 단일 분할이 원인이라고 명시돼 있다. 3-fold + σ로 재측정 가능 |
| **XGB 단순 포함 앙상블** | 671.5 < CatBoost 755.7 | **4** | 차이 84점은 σ를 넘지만 어느 fold·몇 시드인지 불명 |
| 세트포지션(주자 유무) | 찬우 0.60~0.64 | 5 | 내 `outs × base_state`도 두 fold 모두 음수. **일치. 그대로 둔다** |
| 선수 ID 임베딩 | 5명 전원 기각 | 6 | 독립 기각 5건. 우선순위 낮음 |
| TrackMan 물리 피처 | 4/5 기각, 실LB −36.5 | 6 | 실제 리더보드 음수 확인. 우선순위 낮음 |
| 사후 smoothing/sharpening | LOMO −2.52 ~ −5.90 | 7 | 정직한 검증을 이미 통과한 기각. 그대로 둔다 |

**재검토도 예산이 든다.** 1·2번만 이번 사이클에 넣고 3·4번은 팀 결합(Phase E) 이후로 미룬다.
