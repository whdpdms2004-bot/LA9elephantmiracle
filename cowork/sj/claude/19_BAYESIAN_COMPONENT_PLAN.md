# 19. 성분별 확률 모델링 — 계층 베이즈 설계 계획

**목표**: 제구 실패 유형별 확률을 각각 가장 적절한 방식으로 추정하고, 그 확률들로 최종 성공 확률을 합성한다.

**현재 위치**: Public 979 (`submit_032`), 성분 라인 단독 Val2024 745~755, base와의 logit 상관 0.8219.

---

## 0. 이 문서가 바꾸는 것

지금 다섯 성분 모델은 **거의 같은 방식**으로 학습된다. 다른 것은 `base_score`(시즌 외삽)와 `params_for(rate)`가 주는 트리 크기 3단계뿐이다. EB 수축 상수는 **모든 성분에 K=300으로 동일**하다.

그런데 성분마다 분산 구조가 다르다는 것이 실측됐다. 아래 §2가 그 표다. **분산 구조가 다르면 최적 수축도 다르다** — 이것이 이 계획의 1순위 항목이다.

## 1. 라벨 확보 — 이미 검증 완료, 재확인 절차만 정리

### 1-1. 유도식

`train.csv`의 누적 통계에서 각 투구의 라벨을 복원한다.

```
누적카운트(i) = asof_rate(i) × asof_pitcher_n(i)
label(i)      = 누적카운트(i+1) − 누적카운트(i) ∈ {0, 1}
```

투수별로 `asof_pitcher_n` 순서로 정렬한 뒤 인접 차분을 취한다. `asof_pitcher_{success, middle, reverse, ball}_rate` 넷에 각각 적용해 `y_success`, `y_middle`, `y_reverse`, `y_ball`을 얻는다.

### 1-2. 검증 결과 (`p5_failure_labels.py`, 8항목 전부 통과)

| 항목 | 결과 |
|---|---|
| 복원 행 수 | 1,473,508 / 1,475,092 |
| 복원 불가 | 1,584 (첫 투구 NaN 792 + 마지막 투구 792) |
| `y_success` vs `control_success` 일치율 | **100.0000%** |
| 차분값이 {0,1} 밖 | 0행 |
| `M ∨ R ∨ O = 실패` 성립 | 정확히 성립 |
| 7성분 포함-배제 성립 (V35) | 불일치 **0행** |

### 1-3. 세 유형의 정의와 파생

```
M  middle    한가운데
R  reverse   반대 코스
O  OUTSIDE  := 실패 ∧ ¬M ∧ ¬R      (잔여로 정의 — 직접 라벨이 없다)
```

`O`는 `y_ball`로 다시 쪼갠다 (V6에서 +2.64).

```
ob = O ∧ ball      존 밖이고 볼 판정
oz = O ∧ ¬ball     존 밖인데 스트라이크 판정
```

### 1-4. 합성식

```
P(실패) = P(M) + P(R) − P(M∩R) + P(ob) + P(oz)
P(성공) = 1 − P(실패)
```

`O`가 `M∪R`과 배타적이므로 `ob`, `oz`는 교차항이 없다. 추정해야 할 성분은 다섯이다: `m, r, mr, ob, oz`.

### 1-5. 라벨은 학습 전용

추론 경로에 라벨 유도 코드가 없어야 한다. 6단계 검증 2번 항목이 `y_middle` / `y_reverse` 문자열 부재로 기계 확인한다.

## 3. 성분별 모델 설계

### 3-1. 공통 골격

```
logit p_k(i) = β_k(season)          시즌 절편      — 상태공간 외삽
             + α_k(pitcher)          투수 효과      — 계층 수축
             + f_k(context)          상황 함수      — GBDT
```

지금은 `β_k`만 `base_score`로 넣고 나머지를 전부 GBDT에 맡긴다. 세 항을 분리해 각각 적절한 추정기를 붙인다.

### 3-2. 성분별 처방

| 성분 | 시즌 항 `β_k` | 투수 항 `α_k` | 상황 `f_k` |
|---|---|---|---|
| **m** | 선형 추세 외삽 (단조 확인됨) | EB, 중간 수축 | 현행 GBDT |
| **r** | **국소 선형 추세 (비단조 대응)** | **EB, 약한 수축** (투수 신호 최대) | 현행 GBDT |
| **mr** | 선형 외삽 | **EB, 강한 수축** (희소) | 얕은 트리 유지 |
| **ob** | 선형 외삽 | EB, 강한 수축 | **카운트 조건부 강화** |
| **oz** | 거의 평탄 → 최근값 유지 | **EB, 최약 수축** (비 3.88) | **카운트 조건부 최강** |

### 3-3. ★ 1순위 항목 — 성분별 EB 수축 상수

현재 코드는 모든 성분·모든 플래툰 테이블에 `K = 300`을 쓴다. 이론상 최적값은

```
K*_k = σ²_within,k / σ²_between,k
```

`σ²_within`은 이항 분산 `p(1−p)`, `σ²_between`은 §2-2의 투수간 분산이다. 성분마다 다르게 나온다.

| 성분 | p | σ²_within = p(1−p) | σ²_between | **K\* = 비율** |
|---|---:|---:|---:|---:|
| m | 0.176 | 0.1450 | 0.0326² = 0.00106 | **137** |
| r | 0.248 | 0.1865 | 0.0473² = 0.00224 | **83** |
| ob | 0.100 | 0.0900 | 0.0192² = 0.00037 | **244** |
| oz | 0.023 | 0.0225 | 0.0086² = 0.00007 | **304** |

> **현행 K=300은 `oz`에는 거의 맞고 `r`에는 3.6배 과하다.** reverse는 투수 신호가 가장 강한데 가장 세게 수축시키고 있다. 사용자가 지적한 "투수마다 다르다"가 정확히 여기다.

이건 실험이 아니라 **이론적으로 도출되는 수정**이다. 다만 EB 유도값이 유한 표본 추정이므로 fold 검증으로 확인한다.

### 3-4. 시즌 항 — 상태공간

현행 `forecast_base_rate`는 첫 시즌과 마지막 시즌만 잇는 직선이다.

```python
per_year = (last − first) / (year_last − year_first)
forecast = last + per_year
```

`r`처럼 2021에 정점을 찍고 내려오는 성분에서 이 방식은 추세를 과대 추정한다. 대안은 **국소 선형 추세 모델**(random walk + drift)이고, 최근 관측에 더 큰 가중을 준다. 성분별로 `직전유지` / `선형` / `국소선형` 중 fold 검증으로 고른다.

*(V61에서 최종 예측 레벨에 대해 같은 비교를 했고 `harness` 외삽만 두 fold 안전했다. 여기서는 성분별로 다시 판단한다.)*

## 4. 합성 설계

### 4-1. 현행

```
P(성공) = 1 − (p_m + p_r − p_mr + p_ob + p_oz) − c0        c0 = 0.0077
```

`c0`는 2022/2023 OOF 최소제곱으로 적합했고 Val2024 +1.37이었다. 성분별 자유 계수(V26 K1)는 `c_mr` −1.00 → −2.54로 과적합해 −11점, **기각**.

### 4-2. 검토할 대안 — Dirichlet-multinomial 합성

실패 조건부 구성 `(m, r, O)`를 Dirichlet 사전으로 모델링하면 **합이 1이 되는 것이 구조로 보장**된다.

```
P(실패)          단일 이항 모델
(m, r, O | 실패)  Dirichlet-multinomial, 시즌 가변 평균
```

§2-1이 근거다 — 구성비가 시즌에 따라 체계적으로 이동한다(O|fail 0.3604 → 0.2392).

**주의**: 프로덕션이 multiclass를 이미 시험했고 `C4_REVERSE_FIRST` Val2024 **732.43**으로 내 5성분 분해(755)보다 나빴다. 다만 그건 평범한 multiclass이고 Dirichlet 계층 사전이 아니다. **기대값을 낮게 잡고** 우선순위 하위에 둔다.

### 4-3. 불확실성 전파

포함-배제는 선형이라 **평균에 대해서는 점추정으로 충분**하다. 문제는 합성 결과의 보정이고, 이미 `c0`로 경험적으로 잡고 있다. V36에서 platt/isotonic/beta를 시험해 전부 기각했다(최악 fold −114 ~ −162). **추가 보정은 하지 않는다.**

### 5-1. 이미 쓰고 있는 베이지안 요소

> **정적 테이블은 셀이 작아질수록 자기 라벨을 흘린다.** 네 번 관측했다.

>
