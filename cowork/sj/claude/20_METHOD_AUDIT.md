## 0. 결론

**판정 절차 자체에 오류는 없었다.** 다만 **주의해서 읽어야 할 구조적 제약이 두 개** 있고, **미검증 상태로 남은 설계 결정이 하나** 있다.

| | 항목 | 상태 |
|---|---|---|
| 제약 1 | fold 간 base 시스템이 다르다 | 결론을 뒤집지 않음. 해석만 제한 |
| 제약 2 | 플래툰 테이블은 학습 행에 대해 자기 라벨을 조금 흘린다 | 셀이 두꺼워 0.03~0.3%로 유계 |

감사 중 **내 감사 코드에서 오탐이 하나** 났고(라벨 재유도 시 float32 반올림 누락), 고친 뒤 100.000000% 일치를 확인했다.

## 1. 검사 결과

### A. fold 구성 — 통과

```
fold 2022   학습 [2019, 2020, 2021]              -> 검증 2022
fold 2023   학습 [2019, 2020, 2021, 2022]        -> 검증 2023
fold 2024   학습 [2019, 2020, 2021, 2022, 2023]  -> 검증 2024
```

겹침 없음, 미래 시즌 미포함. 순방향 체인이 의도대로다.

### B. 피처 테이블의 fold 의존 — 통과

fold 2023과 2024의 투수 플래툰 테이블이 실제로 다르다(최대차 0.045790, 공통 1,288행). 테이블이 fold마다 학습 시즌만으로 재생성된다는 뜻이다. 2024 테이블이 1,288 → 1,413행으로 커진 것도 시즌 추가가 반영된 증거다.

### C. `season`을 피처로 쓴다 — **미검증 설계 결정**

```
학습 season 값 [2019, 2020, 2021, 2022, 2023]
검증 season 값 [2024]
```

**검증 시즌 값은 학습에 한 번도 없던 값이다.** 트리는 학습 최대값 이상을 한 잎으로 묶으므로, 모델이 시즌 드리프트를 `season` 분할로 학습했다면 검증에서는 **마지막 시즌 규칙이 그대로 적용**된다.

`base_score` 외삽(성분별 2025 기저율)이 이를 보정하는 구조이긴 하다. 그러나 **`season`을 빼는 편이 나은지는 한 번도 안 재봤다.** 전처리 재설계에서 1순위로 볼 항목이다.

### D. 라벨 유도 — 통과 (재검산 완료)

```
유효 1,473,508행 = label_ok 와 정확히 일치 (양방향 불일치 0)
차분값이 {0,1} 밖인 행 0
control_success 와 일치율 100.000000%  (불일치 0행)
포함-배제 = 실패, 불일치 0행 / 1,473,508행
기저율  m 0.1496  r 0.2290  mr 0.0341  ob 0.1085  oz 0.0232
```

> **감사 중 오탐 하나.** `asof_*_rate`가 float32라 `rate × n`의 절대오차가 ~1e-3인데 처음에 허용오차를 1e-6으로 잡아 10,630행만 통과했다. 누적 성공 횟수는 정수이므로 **차분 전에 반올림**해야 한다. 고친 뒤 전량 일치.
>
> 별도로, 캐시 parquet에 `y_success`가 저장돼 있지 않다. 문서에서 반복 인용한 "일치율 100.0000%"를 산출물만으로는 재확인할 수 없었다. **이제 감사 스크립트가 매번 재유도해 검산한다.**

### E. `metrics()` 검산 — 통과

```
수동 계산  836.502890
metrics()  836.502890
null 모델(상수 예측) BSS = -0.000000
```

### F. fold 간 base 시스템이 다르다 — **구조적 제약**

| fold | base 출처 | BSS | 예측평균 | 실제 | 편향 |
|---|---|---:|---:|---:|---:|
| 2022 | enhanced 25종 단순평균 | 2296.92 | 0.53230 | 0.52892 | **+0.338%p** |
| 2023 | enhanced 25종 단순평균 | −140.20 | 0.52237 | 0.49996 | **+2.241%p** |
| 2024 | 프로덕션 `submit_021` | 836.50 | 0.48635 | 0.48610 | **+0.024%p** |

**2024만 시즌 offset이 적용된 프로덕션이고 2022/2023은 보정 없는 단순평균이다.**

- fold 간 ΔBSS **절대값은 비교 불가**하다. 2023의 base가 −140인 것은 그 해가 어려워서만이 아니라 base가 불구여서다.
- 지금까지 판정은 전부 **같은 fold 안에서 arm − 기준선** 형태였다. 이 형태는 base 비대칭의 영향을 받지 않는다.
- "두 fold 모두 양수" 규칙은 **서로 난이도가 다른 두 시험을 함께 통과하라**는 뜻이라 보수적인 방향이다.

> **결론을 뒤집는 종류의 오류는 아니다.** 다만 "2023에서 +40" 같은 수치를 2024의 +40과 같은 크기로 읽으면 안 된다.

### G. 시드 잡음 — 실측

같은 구성을 여러 실행에서 잰 값의 산포:

| | n | 평균 | sd | 범위 폭 |
|---|---:|---:|---:|---:|
| fold 2024 성분단독 | 12 | 744.79 | **1.37** | 4.32 |
| fold 2023 성분단독 | 6 | −1126.10 | **4.87** | 13.41 |

**V61이 세운 "내부 +3 미만은 제출 근거로 쓰지 않는다"가 이 산포와 정합한다.**

단, arm 비교는 같은 실행 안에서 같은 시드로 이뤄지므로 이 산포가 그대로 arm 간 오차는 아니다. 실행 간 재현을 볼 때만 이 크기를 쓴다 — 실제로 V64의 `S0.5_w0.5`(+0.63)가 V72의 `F_short0.5`(−1.74)로 뒤집힌 것이 이 산포 안이다.

### H. 자기 라벨 누수의 한계 — 유계

```
투수 x 타자손 셀 1,413개   중앙 393행   하위10% 23행
EB K=300 에서 한 행의 기여분 = 1/(n+300)
   하위10%  n=23     기여 0.310%
   중앙     n=393    기여 0.144%
   상위10%  n=2,302  기여 0.038%
```

플래툰 테이블은 학습 행 자신의 라벨을 포함한다. 그러나 **셀이 두꺼워 한 행의 기여가 0.03~0.3%**다.

V37(성분별 테이블)과 V35(투수×타자 개별)가 무너진 것은 셀이 얇아서였고, **현행 구성은 그 임계 밖에 있다.** "누수가 0"이 아니라 "유계"라는 뜻이다.

## 2. 실험 방식 정리 (V1~V72)

### 2-1. 공통 절차

```
1. fold 2023 / 2024 (필요시 2022) 에서 성분 라인을 학습
     5성분 (m, r, mr, ob, oz) x 8시드 x (XGBoost + CatBoost) = 80 모델
     피처는 fold 마다 학습 시즌만으로 재생성
2. 합성:  P(성공) = 1 - (p_m + p_r - p_mr + p_ob + p_oz) - c0
3. 결합:  prediction = w(구간) x 성분 + (1-w) x base
4. 판정:  단독 BSS 와 결합 ΔBSS 가 두 fold 모두 기준선 이상
```

### 2-2. 판정 기준의 변천

| 시점 | 기준 | 계기 |
|---|---|---|
| 초기 | Val2024 ΔBSS | — |
| V23 | + 세 fold 확인 | 5개 후보 중 2024 최고를 골랐더니 선택 편향 |
| V33 | + **단독 BSS 동반 상승** | ΔBSS만 오른 것들이 전이가 없었다 |
| V61 | + **내부 +3 미만은 제출 근거로 안 씀** | Public 실측: 내부 ±2.5는 정보가 없다 |
| V65 | + **base와의 상관 하락** | 정확도가 아니라 비상관성이 결합 가치 |

**단일 fold 선별은 네 번 뒤집혔다** — V23, V38, V47, V64.

### 2-3. 발견하고 고친 결함

| 결함 | 영향 | 조치 |
|---|---|---|
| 훅 중복 주입 (`submit_027~029`) | w 0.25가 실효 0.684로 적용 | 구조 불변식 3종을 6단계 검증에 추가 |
| V25 재구성 앵커 오류 | 019(reverse20 없음)를 앵커로 사용 | 기지 지점 재현 검증으로 자체 검출 |
| V40 arm 설계 (추가 vs 교체) | 재표현을 측정 | V43에서 교체로 재측정 |
| V59 커널 공간이 outcome | 자기 라벨 누수, 단독 −211 | V60에서 물리 전용으로 재구성 |

| GPU 동시 실행 (2회) | V40+스모크, V66+V69 결과 손실 | `run_queue.py`로 순차 강제 |
